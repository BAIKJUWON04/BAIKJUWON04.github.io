GitHub Pages와 **Jekyll Chirpy**를 기반으로 개발 블로그를 구성했습니다.

## 블로그 목적

이 블로그에서는 다음 내용을 기록합니다.

- 포트폴리오
- 임베디드 개발
- 개발 공부
- 컴퓨터과학 공부
- 외부활동

## 글 작성 원칙

본문은 가능한 한 순수한 Markdown 문법을 사용합니다.

```c
#include <stdio.h>

int main(void)
{
    int number;

    number = 10;

    printf("%d\n", number);

    return 0;
}
```

이렇게 작성하면 향후 다른 Markdown 기반 플랫폼으로 옮기기도 쉽습니다.
