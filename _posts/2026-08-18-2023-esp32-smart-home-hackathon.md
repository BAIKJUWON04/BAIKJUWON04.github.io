## 서론

그동안 여러 해커톤과 프로젝트를 시도했지만, 이번처럼 팀원들과 호흡이 잘 맞았던 경험은 드물었다.

각자 맡은 역할이 분명했고, 필요한 순간에는 서로의 작업을 자연스럽게 도왔다.  
무엇보다 **내가 잘할 수 있는 하드웨어 제작과 임베디드 쪽 역할을 맡아 팀에 기여할 수 있었다는 점**이 좋았다.

결과적으로 이 프로젝트는 **2023 국립안동대학교 전교생 해커톤 우수상**을 수상했다.

![2023 국립안동대학교 전교생 해커톤 우수상](/assets/img/projects/2023-esp32-smart-home/award-photo.jpg)

## 프로젝트 개요

| 구분 | 내용 |
|---|---|
| 프로젝트명 | ESP32 기반 웹 제어 스마트홈 |
| 참가 행사 | 2023 국립안동대학교 전교생 해커톤 |
| 결과 | 우수상 |
| 개발 형태 | 4인 팀 프로젝트 |
| 핵심 장치 | ESP32 |
| 분야 | 임베디드 시스템 · 사물인터넷 · 웹 기반 하드웨어 제어 |
| 나의 역할 | 회로 설계 · 납땜 · 배선 · 스마트홈 모형 제작 |

프로젝트의 핵심은 별도의 외부 서버나 공유기 없이 **ESP32 자체 무선망과 웹 서버만으로 스마트홈 장치를 제어하는 것**이었다.

사용자는 스마트폰이나 노트북으로 ESP32가 만든 무선망에 접속한 뒤, 웹 브라우저를 통해 조명과 블라인드, 현관문 등을 제어할 수 있다.

---

## 왜 스마트홈이었나

짧은 해커톤 시간 안에 결과물을 보여주려면 단순히 코드만 실행되는 프로젝트보다는 **직접 눈으로 동작을 확인할 수 있는 결과물**이 필요하다고 생각했다.

그래서 센서와 서보모터, 조명 등을 이용해 실제 집처럼 동작하는 스마트홈 모형을 제작했다.

![스마트홈 모형 제작 과정](/assets/img/projects/2023-esp32-smart-home/minecraft-model.jpg)

단순한 전자회로 실습보다는 **실제 제품처럼 보이는 결과물**을 만들고 싶었다.

---

## 구현 기능

- 실내 온도 측정 및 웹페이지 표시
- 네오픽셀 조명 색상 제어
- 메인 조명 밝기 단계 제어
- 블라인드 열기 및 닫기
- 조도 센서 기반 자동 블라인드
- 현관문 열기 및 닫기
- 적외선 센서 기반 자동 현관문
- 움직임 감지 시 부저 경고음 출력

핵심은 **웹 브라우저가 제어 화면이 되고 ESP32가 동시에 서버와 제어기의 역할을 수행한다는 점**이다.

```text
스마트폰 / 노트북
        ↓
ESP32 자체 무선망 접속
        ↓
ESP32 웹 서버
        ↓
센서 값 확인
        ↓
조명 / 블라인드 / 현관문 / 부저 제어
```

---

## 내가 맡은 역할

### 회로 설계와 배선

센서와 발광 다이오드, 서보모터, 부저를 ESP32에 연결하고 전체 배선을 구성했다.

해커톤에서는 시간이 부족하기 때문에 회로가 한 번 꼬이면 소프트웨어 테스트까지 같이 밀릴 수 있다.

그래서 각 기능을 하나씩 연결하고 동작을 확인하면서 전체 회로를 구성했다.

### 납땜

브레드보드에서 테스트가 끝난 부품 일부는 실제 모형에 고정하고 사용할 수 있도록 납땜했다.

단순히 연결만 되는 것이 아니라, 모형을 움직이거나 발표 과정에서 흔들려도 배선이 쉽게 빠지지 않도록 만드는 것이 중요했다.

### 스마트홈 모형 제작

센서와 구동부를 그냥 책상 위에 놓는 것이 아니라 실제 집처럼 보이도록 모형에 배치했다.

블라인드와 현관문은 서보모터의 움직임이 실제 구조물과 연결되어야 했기 때문에, 프로그램뿐만 아니라 **기구적인 위치와 움직임**까지 고려해야 했다.

---

## 웹으로 하드웨어를 제어하다

ESP32가 직접 웹페이지를 제공하고, 사용자가 버튼을 누르면 해당 요청을 받아 장치를 제어하도록 구성했다.

```text
사용자 버튼 선택
      ↓
웹 브라우저 요청
      ↓
ESP32 웹 서버
      ↓
요청 주소 확인
      ↓
해당 장치 제어 함수 실행
      ↓
조명 또는 서보모터 동작
```

별도의 전용 응용프로그램을 설치하지 않아도 스마트폰 웹 브라우저만으로 제어할 수 있다는 점이 장점이었다.

---

## 자동 블라인드

블라인드는 서보모터와 조도 센서를 이용했다.

수동 모드에서는 웹페이지에서 직접 블라인드를 열고 닫을 수 있고, 자동 모드에서는 주변 밝기에 따라 블라인드가 움직이도록 만들었다.

```text
자동 모드 활성화
      ↓
조도 센서 측정
      ↓
기준값 비교
   ↙       ↘
밝음       어두움
 ↓           ↓
닫기        열기
```

---

## 자동 현관문과 경고 기능

현관문에도 서보모터를 사용했다.

웹페이지에서 직접 문을 열고 닫을 수 있으며, 자동 기능이 켜진 상태에서는 적외선 센서가 움직임을 감지하면 문을 제어하고 부저로 경고음을 출력하도록 구성했다.

여러 센서와 출력장치를 단순하게 따로 동작시키는 것이 아니라 **센서 입력 → 판단 → 구동부 제어** 흐름을 하나의 시스템으로 묶는 경험이었다.

## 후기

그동안 많은 해커톤을 시도했지만 이번처럼 팀원이 정말 좋았던 적은 없었던 것 같다.

각자 맡은 일을 하면서도 필요한 순간에는 자연스럽게 서로 도왔다.  
누군가에게 계속 일을 떠넘기거나 한 사람이 모든 것을 끌고 가는 분위기도 아니었다.

나는 회로와 배선, 납땜, 모형 제작처럼 내가 잘할 수 있는 부분에 집중할 수 있었고, 다른 팀원들도 자신의 역할을 해줬다.

그래서 처음으로 **“아, 팀 프로젝트가 이렇게 하면 정말 재미있을 수 있구나”**라는 생각을 했다.

드디어 나와 맞는 동료와 함께해서 행복했다.

해커톤에서 상을 받은 것도 기억에 남지만, 시간이 지나고 다시 생각해 보면 우수상보다 **좋은 팀원들과 하나의 결과물을 끝까지 만들어 본 경험**이 더 크게 남아 있다.

---

## 이 프로젝트에서 얻은 것

### 임베디드 시스템은 코드만으로 끝나지 않는다

프로그램이 정상적으로 실행되어도 실제 배선이 잘못되거나, 서보모터 위치가 맞지 않거나, 전원이 불안정하면 결과물은 제대로 움직이지 않는다.

이 프로젝트를 통해 임베디드 개발에서는 소프트웨어와 하드웨어를 함께 보는 것이 중요하다는 점을 다시 느꼈다.

### 빠르게 동작하는 결과물을 만드는 능력

해커톤에서는 완벽한 설계보다 제한된 시간 안에 실제로 동작하는 결과물을 완성하는 것이 중요했다.

기능을 한꺼번에 구현하기보다 하나씩 확인하면서 전체 시스템으로 확장해 나가는 방식이 효과적이었다.

### 팀원의 중요성

기술만큼 크게 배운 것은 협업이었다.

나와 역할과 성향이 맞는 사람들과 함께할 때 개발 속도뿐만 아니라 프로젝트 자체의 즐거움도 크게 달라진다는 것을 경험했다.
